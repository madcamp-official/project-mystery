# WF-16 확대 조사 파일럿 구현 기록

## 적용 범위

현장 조사 파일럿은 다음 기록에 적용한다.

- `C-01` 다니엘의 초대장
- `C-02` 열린 출입문
- `C-03` 외벽 발판
- `C-04` 덕트 먼지
- `C-05` 점검구 먼지
- `C-07` 혈흔 중심

내부 코드는 저장·검증에만 사용하며 플레이어 화면에는 자연어 이름만 표시한다.
나머지 기록은 기존 프로덕션 진행을 유지하고, 파일럿 검증 후 같은 카탈로그로
순차 이관한다.

## 사용자 흐름

```text
탐색 대상 또는 조사 대사
→ WF-16 확대 조사
→ 필수 세부 지점 관찰
→ 에이드리언 관찰 문장
→ 조사 기록에 남기기
→ 기존 우측 신규 기록 큐 알림
→ 확대 조사 또는 원래 진행으로 복귀
```

최초 클릭과 조사 대사 확인만으로는 파일럿 기록이 지급되지 않는다.
`InvestigationTargetCatalog`의 필수 지점을 모두 확인한 뒤 우하단의 단일 주
행동을 실행해야 `EvidenceInventory`에 정식 기록이 추가된다.

세부 관찰 완료 상태는 `GameStateManager` 플래그로 저장되므로 재접속 후에도
유지된다. 기존 저장 파일에 이미 기록 ID가 있으면 완료된 조사로 취급하여
호환성을 유지한다.

`C-03`, `C-04`, `C-05`를 모두 기록하면
`sealed_exits_conclusion` 중간 결론을 한 번만 등록한다.

## 입력과 표시

- 조사 지점은 평상시 투명하며 호버·키보드 포커스에서만 표시한다.
- 접근성 조사 표시가 켜져 있으면 모든 지점을 약하게 표시한다.
- 완료 지점은 체크 아이콘 대신 청회색의 미세한 표면 변화로 구분한다.
- 확대는 1~2배, 회전은 90도 단위이며 초기화할 수 있다.
- 조사 모달은 독립 `overrideSorting` Canvas와 `GraphicRaycaster`를 사용해
  배경 클릭 관통을 막는다.
- 닫을 때 탐색 카메라나 배경 Transform을 수정하지 않으므로 기존 현장 상태로
  복귀한다.

## 에셋

파일럿은 기존 `Assets/_Project/Art/Evidence/evidence_cXX.png` 이미지를
확대 이미지로 사용한다. 현재 여섯 대상은 필요한 대표 이미지가 모두 있으므로
신규 이미지를 생성하지 않았다. 후속 다중 시점에서 별도 이미지가 필요하면
기존 어두운 청회색 선상 미스터리 화풍을 유지한 투명 PNG로 추가한다.

## 후속 범위

- 나머지 12개 정식 기록을 조사 대상 카탈로그로 이관
- 도구·순서·비교·수동 결론 완료 규칙 연결
- 조사 기록을 열고 닫을 때 확대·회전 상태를 그대로 복원
- WF-17 목록·검색·분류 및 WF-18 병렬 비교 화면
- 1280×720, 1920×1080, 16:10 화면 회귀 캡처
