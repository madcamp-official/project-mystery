# 인물 관계도 수동 QA 체크리스트

## 목적

인물 관계도에서 돌아가기 버튼이 항상 노출되고 클릭 가능하며,
인물 카드를 선택했을 때 해당 인물의 상세 정보가 올바르게 표시되는지 확인한다.

## 사전 조건

- `UI Basic Scene`을 연다.
- 새 게임 또는 이어하기로 인게임 HUD가 표시되는 지점까지 진행한다.
- 증거 수첩 아이콘을 눌러 수첩을 연다.

## 화면 비율별 레이아웃

- 1920×1080(16:9)에서 관계도 목록과 돌아가기 버튼이 겹치지 않는다.
- 1920×1200(16:10)에서 관계도 목록과 돌아가기 버튼이 겹치지 않는다.
- 1440×1080(4:3)에서 관계도 목록과 돌아가기 버튼이 겹치지 않는다.
- 각 화면 비율에서 돌아가기 버튼 전체가 화면 안에 표시된다.
- 각 화면 비율에서 돌아가기 버튼을 한 번 클릭해 수첩을 닫을 수 있다.

## 인물 카드와 상세 정보

- `인물 · 관계` 탭을 열면 발견한 인물 카드가 목록에 표시된다.
- 아드리안 베일 카드를 누르면 이름, 역할, 소속, 신뢰도와 인물 설명이 표시된다.
- 클레어 쇼 카드를 누르면 클레어의 정보가 표시된다.
- 다니엘 머서 카드를 누르면 다니엘의 정보가 표시된다.
- 리처드 휴스를 비롯한 나머지 주요 인물 카드도 서로 다른 프로필을 표시한다.
- 인물 초상화가 선택한 카드와 일치한다.
- 현재 신뢰도 수치가 상세 화면에 반영된다.
- 발견 조건을 충족한 인물은 조사 메모가 표시된다.
- 발견 조건을 충족하지 않은 인물은 잠긴 조사 메모 안내가 표시된다.

## 상세 화면 이동

- 상세 화면의 `목록으로` 버튼을 누르면 인물 카드 목록으로 돌아간다.
- 목록으로 돌아왔을 때 카드 스크롤과 탭이 정상 동작한다.
- 상세 화면에서 수첩을 닫았다가 다시 열어도 입력을 가리는 투명 패널이 남지 않는다.
- 관계도 목록의 돌아가기 버튼이 다른 UI보다 앞에서 클릭 입력을 받는다.

## 회귀 점검

- `조사 기록` 탭 전환과 증거 카드 선택이 기존과 동일하게 동작한다.
- 증거 상세 화면의 돌아가기 동작이 유지된다.
- 인물 관계도 스크롤 영역 밖의 HUD가 의도치 않게 클릭되지 않는다.
- 설정 및 지도 아이콘의 동작에 변화가 없다.
- Console에 `MissingReferenceException`, `NullReferenceException` 또는 UI 레이캐스트 오류가 없다.

## 자동 검사

- `CharacterRelationshipProfileCatalogTests`가 프로필 ID 중복과 필수 데이터를 검사한다.
- `RuntimeUiLayoutSceneIntegrityTests`가 관계도와 돌아가기 버튼의 영역 중첩을 검사한다.
- `UiRuntimeBootstrapPlayModeTests`가 카드 선택, 상세 표시, 목록 복귀와 수첩 닫기를 검사한다.
